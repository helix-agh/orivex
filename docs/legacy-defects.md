# Verified legacy defects and compatibility decisions

Reference implementation: `pflacco` 1.2.2 at commit `4689566` (2023-08-25).

This catalogue distinguishes corrected bflacco definitions from any future explicit
`pflacco-1.2.2` compatibility definitions. Legacy behavior is never enabled through an
ambiguous Boolean flag.

| ID | Area | Verified behavior | Corrected-definition disposition |
| --- | --- | --- | --- |
| LEGACY-001 | Packaging | Scientific dependencies have narrow 2023 upper bounds; importing sampling requires unmaintained `pyDOE`. | Use modern lower bounds, no routine upper pins, and isolate optional dependencies. |
| LEGACY-002 | NumPy 2 | Cell mapping calls removed `np.product`; another helper calls removed `np.find_common_type`. | Use supported APIs and test the newest NumPy release in CI. |
| LEGACY-003 | Curvature | An `(N, 3)` derivative matrix is reshaped to `(3, N)`, interleaving quantities across observations. | Transpose explicitly and test each per-point quantity before aggregation. |
| LEGACY-004 | Curvature | `grad_norm` is computed from the scalar gradient max/min ratio and is therefore identical to `grad_scale`. | Specify and calculate the actual gradient norm independently. |
| LEGACY-005 | Length scale | The global RNG is reset inside every Levy-walk iteration, producing repeated collinear increments. | Accept one explicit generator and never reseed inside a kernel. |
| LEGACY-006 | Length scale | `cov != inf or cov != nan` is always true, leaving the fallback branch dead. | Use finite-value predicates and specified degenerate behavior. |
| LEGACY-007 | Sampling | Sobol sampling always uses seed 50, ignoring the public seed argument. | Pass an explicit generator/seed and test distinct-seed behavior. |
| LEGACY-008 | Sobol indices | SALib's Sobol analyzer receives a plain QMC Sobol sequence instead of the required structured A/B/AB design. | Implement the specified estimator with a valid design or delegate through a verified optional backend. |
| LEGACY-009 | Information content | Symbols are calculated in the order of `ic_epsilon`, while outputs are indexed using its sorted unique form. Custom unsorted or duplicate epsilon values silently misalign results. | Normalize epsilon once before every dependent calculation. |
| LEGACY-010 | Fitness-distance correlation | `proportion_of_best=1` leaves `fopt_idx` undefined. | Define optimum selection for the complete interval and cover boundary values. |
| LEGACY-011 | Meta model | The named quadratic-interaction design multiplies already-squared columns, introducing cubic and quartic terms. | Specify the design matrix term-by-term and version any legacy polynomial definition separately. |
| LEGACY-012 | Cell mapping | `_create_blocks` contains `X, y, _validate_variable_types(X, y)`, which evaluates and discards the validation result. | Validate once at a typed public boundary. |
| LEGACY-013 | Local-optima network | Construction stores callback state in module globals and updates neutrality through chained pandas assignment. | Store run state in an instance and use unambiguous indexed updates. |
| LEGACY-014 | Input handling | Validation renames caller-owned DataFrame columns in place. | Convert without mutating caller-owned objects. |
| LEGACY-015 | Tests | Golden pickles are generated by the implementation under test and maintained separately by OS. | Triangulate analytical, metamorphic, R differential, and legacy compatibility evidence. |
| LEGACY-016 | R flacco 1.8 meta model | `calculateAdjustedR2` uses the model's residual degrees of freedom as `n` and its rank (including the intercept) as `p`, applying the degrees-of-freedom correction twice and off by one. | Use the observation count and number of non-intercept predictors in the standard adjusted-R-squared formula; retain the R value only in an explicitly versioned compatibility definition. |

Before reporting a defect upstream, add a minimal reproducer and determine whether the current R
`flacco` definition shares the behavior.
